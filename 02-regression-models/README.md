# Regression Models

Construction and statistical analysis of linear and nonlinear regression models.

## Notebook contents

- estimation of regression parameters;
- covariance matrix and residual-variance estimation;
- `R²` and adjusted `R²`;
- confidence intervals for model parameters and variance;
- individual and joint hypothesis tests for parameters;
- regression with non-constant error variance;
- comparison of alternative sets of basis functions;
- four reproducible computational experiments.

## Run

Open `analysis.ipynb` in Jupyter Notebook or JupyterLab and run all cells.
