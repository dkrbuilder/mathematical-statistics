# Mathematical Statistics

## Projects

| Project | Topics | Technologies |
|---|---|---|
| [One-way ANOVA](01-one-way-anova/) | Comparison of several normal populations, Fisher statistic, p-value, hypothesis testing | Python, NumPy, pandas, SciPy, Matplotlib |
| [Regression models](02-regression-models/) | Parameter estimation, confidence intervals, hypothesis tests, heteroscedasticity, model comparison | Python, NumPy, pandas, SciPy, Matplotlib |

## Installation

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter notebook
```

## Skills demonstrated

- statistical hypothesis testing;
- one-way analysis of variance;
- linear and nonlinear regression;
- weighted estimation with non-constant error variance;
- confidence intervals and tests for regression parameters;
- model comparison using `R²` and adjusted `R²`;
- reproducible simulations and data visualization.
